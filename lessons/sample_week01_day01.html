📖 이론 3 — 핵심 단축키 (매일 수백 번 쓰는 것들)

H키 — 좌우 반전 ★★★ 가장 중요

🔄 H키 반전 — 네비게이터 + 메뉴 + 단축키 3가지 방법
출처: pipelinecomics.com — How to Flip an Image
💡 왜 H키가 중요한가?
사람의 눈은 같은 방향으로 계속 보면 뇌가 오류를 보정해버린다. 반전하면 오류가 즉시 보인다. 프로 일러스트레이터는 5분에 한 번 이상 H키를 누른다.

R키 — 캔버스 회전

🔃 R키 캔버스 회전 가이드
출처: doncorgi.com — How to Rotate the Canvas in CSP

불편한 방향의 선을 억지로 긋지 마라. 캔버스를 내가 편한 방향으로 돌리면 모든 방향의 선이 편해진다. 돌아간 캔버스를 원상복구 할 때는 F키.

단축키기능중요도 & 설명
H 좌우 반전 ★★★ 선 오류 즉시 발견. 5분에 한 번 이상 필수.
R 캔버스 회전 불편한 각도를 편한 방향으로. 선 품질 즉시 향상.
Space 캔버스 이동 누르는 동안 손바닥 도구로 임시 전환.
[ / ] 브러시 크기 ± 작업 중 빠르게 브러시 크기 조절.
Ctrl+Z 실행 취소 기본 중의 기본. 겁내지 말고 그려라.
F 화면 맞추기 캔버스를 화면에 꽉 차게. 회전 리셋도 포함.
Ctrl+T 변형(Transform) 그린 것의 크기/위치/기울기 조절.
✏️ 실습 순서
1
모든 패널 직접 찾아보기 (30분)
위 표의 패널 6개를 각각 클릭해서 화면에서 실제 위치 확인.
패널이 없으면 메뉴바 → 윈도우 → 해당 패널 이름 체크.
2
새 캔버스 만들고 단축키 7개 연습 (1시간)
파일 → 신규 → A4, 350dpi, RGB 컬러.
H / R / Space / [ / ] / F / Ctrl+Z 각 10번씩. H키를 가장 많이 써볼 것.
3
브러시 3종 비교 (30분)
도구 팔레트 → 펜 → 서브 도구에서 G펜 / 연필 / 에어브러시 각각 선 5개 그어보기.
굵기, 텍스처, 끝 처리 차이 느끼기.
4
레이어 구조 연습 (1시간)
레이어 3개 만들고 → 각각에 다른 브러시로 선 그리기 → 순서 바꾸기.
눈 아이콘(숨기기), 이름 변경, 삭제, 복제 연습.
