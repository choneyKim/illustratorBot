📖 이론 — 브러시의 원리와 G펜을 쓰는 이유

왜 브러시 설정부터 시작하는가?

스타레일·명조 스타일 일러스트의 선화는 굵기 변화가 선의 생명이다. 손목 힘의 강약이 선의 두께로 그대로 전달될 때, 선 하나에도 캐릭터의 무게감·방향감이 담긴다. 잘못된 브러시 설정은 아무리 많이 연습해도 "기계적인 선"을 만든다. 오늘 올바르게 설정해두면 이후 16주가 전부 달라진다.

프로 현업 팁: 프리랜서 애니 일러스트레이터들이 새 작업을 시작할 때 가장 먼저 하는 일이 브러시 프리셋 확인이다. 브러시는 화가의 붓과 같다 — 처음 한 번 제대로 설정하면 수년간 같은 브러시를 쓴다.

G펜(G-pen)이란 무엇인가?

G펜은 원래 일본 만화가들이 사용하던 금속 딥 펜(dip pen) 촉의 이름이다. CSP의 G펜 브러시는 이 물리적 특성을 디지털로 재현한다:

  • 필압이 낮을 때: 날카롭고 가는 선 → 머리카락 끝, 눈꺼풀 아래쪽 디테일
  • 필압이 높을 때: 두껍고 강한 선 → 윤곽선, 눈꺼풀 위쪽, 옷 접힘
  • 불투명도 100% 고정: 선이 항상 깔끔하게 끊긴다 (수채 계열 브러시처럼 번지지 않음)
약한 필압
1~3px
중간 필압
5~8px
강한 필압
12~15px
초보자가 자주 하는 실수: 처음에 브러시 크기를 너무 크게 설정(20px 이상)한다. 스타레일/명조 스타일의 정교한 선화는 최대 15px 안에서 필압으로 굵기를 조절하는 방식이 정석이다. 크기가 너무 크면 필압 차이가 선에 표현되지 않는다.

필압 곡선(Pressure Curve)의 원리

필압 곡선은 "S펜에 가하는 실제 힘"과 "화면에 나타나는 선 굵기" 사이의 관계를 정의하는 그래프다. 곡선이 왼쪽 위로 볼록하면 조금만 눌러도 굵어지고, 오른쪽 아래로 볼록하면 세게 눌러야 굵어진다.

갤럭시 탭 S11 Ultra + S Pen 환경에서 권장하는 설정:

  • 전체 필압 조정 경로: 파일 ▶ 환경설정 ▶ 태블릿 ▶ 필압 조정
  • 브러시별 필압 조정 경로: 서브 도구 팔레트 ▶ 브러시 더블클릭 ▶ 서브 도구 상세 ▶ 브러시 크기 ▶ 필압 아이콘
S Pen 전용 팁: 갤럭시 탭의 S Pen은 4096레벨 필압을 지원하지만, CSP의 기본 필압 감도가 갤럭시 탭에 최적화되어 있지 않을 수 있다. 처음 설정 후 반드시 파일 → 환경설정 → 태블릿 → 필압 조정에서 실제로 선을 그어보며 본인의 손 힘에 맞게 조정해야 한다.

딱딱한 브러시 vs 부드러운 브러시: 언제 무엇을 쓰는가?

브러시 종류 특성 스타레일/명조에서 사용 상황
G펜 (선화용) 경계 선명, 불투명도 100%, 필압으로 굵기 변화 캐릭터 모든 윤곽선, 눈·코·입·머리카락 선화
수채 평붓 → 플랫 채색용 경계 선명, 필압 최소화, 불투명도 100% 고정 피부·의상·머리카락 베이스 단색 플랫 채색, 마스킹
에어브러시 → 그라데이션용 경계 부드러움, 불투명도 30~60% 유동적 볼 홍조, 피부 그라데이션, 하늘 배경, 발광 효과
스타레일/명조 스타일 특징: 두 게임 모두 플랫 채색 + 셀 쉐이딩 기반이다. 이는 "채색용 플랫 브러시"로 영역을 정확히 채운 뒤, 그라데이션 브러시로 부드러운 전환을 추가하는 방식이다. 초반에 이 두 브러시를 구분해서 익히는 것이 나중에 채색 레이어 관리에 결정적인 영향을 준다.
✏️ 실습 순서
1
1000×1000px, 350dpi 연습용 캔버스 생성
파일 → 신규 → 일러스트 선택.
너비·높이 1000px, 해상도 350dpi, 기본 표현색 컬러로 설정.
왜 350dpi인가? 72dpi는 화면 전용이고, 300~350dpi가 고화질 출력과 세밀한 선화 모두 커버한다. SNS에 올려도 품질 손실이 없다.
2
도구 팔레트에서 G펜 찾기 → 5px·10px·15px 크기 테스트
도구 팔레트의 펜 클릭 → 서브 도구 팔레트에서 G펜 선택.
도구 속성 팔레트에서 브러시 크기를 5 / 10 / 15px로 바꿔가며 각각 10개씩 자유롭게 선 긋기.
필압을 약하게·중간·세게 달리하며 굵기 차이를 확인한다.
3
필압 곡선 개인화 조정
서브 도구 팔레트 → G펜 더블클릭 → 서브 도구 상세 열기
왼쪽 항목에서 브러시 크기 클릭 → 오른쪽에 "필압" 아이콘(그래프 모양) 클릭 → 커브 그래프 편집.
목표: 가볍게 누르면 가늘게(곡선 아래쪽 낮게), 세게 누르면 확실히 굵어지게(오른쪽 위 높게).
조정 후 캔버스에서 같은 선을 다시 그어 차이를 비교한다.
4
브러시 이름 변경 → "선화용_메인" + 즐겨찾기 등록
서브 도구 상세 패널 맨 위 이름 칸 클릭 → 선화용_메인 입력 후 확인.
서브 도구 팔레트에서 브러시 우클릭 → 서브 도구를 즐겨찾기에 추가 선택.
이렇게 하면 다음에 CSP를 열었을 때 즐겨찾기 탭에서 바로 불러올 수 있다.
5
"수채 평붓" 찾기 → "채색용_플랫" 설정
도구 팔레트 붓 → 서브 도구 팔레트에서 수채 → 수채 평붓 찾기.
서브 도구 상세 열기:
 • 브러시 크기: 필압 영향 최소화 (필압 아이콘 비활성화 또는 최솟값 올리기)
 • 불투명도: 100% 고정, 필압 영향 끄기
 • 경도: 100 (경계가 선명하게)
이름을 채색용_플랫으로 변경 후 즐겨찾기 등록.
6
"에어브러시" 찾기 → "채색용_그라데" 설정
도구 팔레트 에어브러시 → 서브 도구 팔레트에서 부드러운 에어브러시 선택.
서브 도구 상세 열기:
 • 브러시 크기: 30~80px 범위, 필압으로 크기 조절 활성화
 • 불투명도: 30~60% 범위로 설정, 필압에 따라 불투명도 변화
 • 경도: 0~30 (경계가 흐릿하게 — 그라데이션 목적)
이름을 채색용_그라데로 변경 후 즐겨찾기 등록.
7
3종 브러시 전체 테스트 — A4 한 장 채우기
새 레이어를 3개 만들고 각 브러시로 다음을 그린다:
 • 선화용_메인: 직선 10개(필압 변화), 곡선 10개, 원 5개 — 가는 선부터 굵은 선까지
 • 채색용_플랫: 사각형 / 원 / 자유 형태 색 면 채우기
 • 채색용_그라데: 색에서 흰색으로 자연스럽게 페이드되는 그라데이션 3개
완성 후 3가지가 어떻게 다른지 확인하고 메모한다.
초보자가 여기서 막히는 포인트: "서브 도구 상세가 어디 있는지 모르겠다"는 경우가 많다. 서브 도구 팔레트 하단 오른쪽에 작은 렌치(공구) 아이콘을 클릭하면 열린다. 또는 브러시를 더블클릭해도 된다.

3종 브러시 테스트 시트 스크린샷 제출

하나의 캔버스에 3개 레이어(선화용_메인 / 채색용_플랫 / 채색용_그라데)로 나눠 각 브러시를 테스트한 결과물을 스크린샷으로 제출한다.

필수 확인 항목:
  • 선화용_메인에서 필압 약→강에 따른 굵기 변화가 보이는 선이 최소 5개
  • 채색용_플랫으로 경계가 선명한 색 면이 있을 것
  • 채색용_그라데로 흐릿하게 번지는 그라데이션이 있을 것
  • 레이어 패널이 보이도록 스크린샷 (이름이 보여야 함)
⏱ 예상 시간: 평일 3시간 (설정 1.5h + 테스트 드로잉 1.5h)
