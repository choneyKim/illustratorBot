환경 세팅 완성

2일차 — 단축키 & S Pen 버튼 설정

🎯 1주 2일차 목표

키보드 없이 갤럭시 탭 + S Pen만으로 CSP 풀 작업이 가능한 환경을 완성한다.

📖 이론 — 프로 태블릿 작업 흐름

왜 단축키 세팅이 그림 실력만큼 중요한가?

프로 일러스트레이터는 도구 전환 시간이 집중력을 끊는다는 것을 알고 있다. 팔레트를 클릭하러 펜을 움직이는 0.5초가 드로잉의 리듬을 망가뜨린다. 잘 세팅된 단축키 환경에서는 뇌가 "다음 선을 어떻게 그을까"에만 집중할 수 있다.

갤럭시 탭에서의 양손 작업 대체법

PC 환경에서 프로들은 왼손 키보드 + 오른손 타블렛으로 작업한다. 갤럭시 탭은 키보드가 없으므로 이를 대체하는 세 가지 수단이 있다:

  • S Pen 버튼 — 짧게 누르기 / 길게 누르기 2가지 동작 할당 가능
  • 퀵 액세스 팔레트 — 화면 한 구석에 상주하는 미니 툴바 (최대 10개)
  • 제스처 조작 — 손가락 탭/스와이프로 실행취소·확대·회전
📌 CSP 퀵 액세스 팔레트 — 자주 쓰는 도구를 한 곳에 모아두면 터치 한 번으로 전환 가능
출처: CLIP STUDIO TIPS  ·  🔗 원문 보기 →

S Pen 버튼 2단계 설정 원리

갤럭시 탭의 S Pen 사이드 버튼은 짧게 누르기와 길게 누르기로 각각 다른 동작을 연결할 수 있다. 이 두 가지 동작을 제대로 설정하면 그리는 중에 손을 화면에서 뗄 필요가 없다.

  • 짧게 누르기 → 지우개 전환: 실수한 선을 즉시 지울 수 있어 가장 많이 쓰는 단축키
  • 길게 누르기 → Ctrl+Z (실행 취소): 드로잉의 생명줄. 망설임 없이 취소 가능
💡 현업 팁: 스타레일·명조 스타일처럼 선화가 많은 그림은 지우개와 실행취소를 수백 번 사용한다. 이 두 가지를 S Pen 버튼에 할당해두면 실제 드로잉 속도가 체감상 2배 이상 빨라진다. 전문 일러스트레이터도 "세팅에 하루를 투자하면 1년을 번다"고 한다.

CSP 기본 단축키 (갤럭시 탭 필수 5개)

⌨️ 반드시 알아야 할 CSP 단축키 (화면 탭 기준)
  • 손가락 2개 탭 — 실행 취소 (Ctrl+Z 대체)
  • 손가락 3개 탭 — 재실행 (Ctrl+Y 대체)
  • 손가락 2개 핀치 — 캔버스 확대/축소
  • 손가락 2개 회전 — 캔버스 회전 (선 긋기 편한 각도로!)
  • 손가락 2개 길게 누르기 — 스포이드 (색상 추출)
📌 갤럭시 탭 S Pen Air Actions — CSP 메뉴에서 버튼별 동작 지정 가능
출처: Clip Studio Paint 공식 도움말  ·  🔗 원문 보기 →
💡 현업 팁 (CSP 조작 경로):
S Pen Air Action 설정 경로:
CSP 메뉴 → [Clip Studio Paint] → [Air Action Settings]
단축키 설정 경로:
파일(File) → 단축키 설정(Shortcut Settings) → 펜/제스처(Pen/Gesture)

✏️ 실습 순서

1
CSP 단축키 설정 열기

CSP 실행 → 상단 메뉴 파일 → 단축키 설정

"도구 전환" 카테고리에서 자주 쓸 브러시/지우개 단축키를 확인하거나 수정한다.
지금 당장 바꾸지 않아도 괜찮다 — 어디서 바꾸는지 경로만 숙지한다.
2
S Pen 버튼 설정 — CSP 내부

메뉴 → [Clip Studio Paint] → Air Action Settings

짧게 누르기: "서브 도구 전환 (지우개)" 또는 "지우개 일시 전환"으로 설정
길게 누르기: "실행 취소" (Ctrl+Z) 로 설정
→ OK 버튼으로 적용
3
갤럭시 설정에서 S Pen 활성화 확인

갤럭시 설정 앱 → 고급 기능 → S Pen → Air Actions → CSP 앱 ON

Air Actions가 꺼져 있으면 버튼 설정이 동작하지 않는다. 반드시 활성화할 것.
4
퀵 액세스 팔레트 5종 배치

메뉴 → 창(Window) → 퀵 액세스(Quick Access) → 팔레트 열기

팔레트 하단 렌치 아이콘(퀵 액세스 설정) 클릭 →
추천 5종 등록:
① G펜 (선화용 브러시)
② 지우개
③ 올가미 선택 (Lasso)
④ 채우기 (버킷)
⑤ 손 도구 (캔버스 이동)
5
퀵 액세스만으로 10분 자유 드로잉 연습

마우스·키보드·화면 하단 툴바는 일절 사용 금지. 오직 S Pen + 퀵 액세스만 사용한다.

낙서 내용은 뭐든 상관없다 — 동그라미, 사각형, 간단한 얼굴 등.
목적은 "손가락이 팔레트로 자동으로 가는 근육 기억" 형성이다.
💡 프로 워크플로우 팁: 처음 세팅할 때는 "최적의 배치"를 고민하지 말 것. 일단 아무거나 등록하고 써보면서 "이게 불편하다"는 경험이 쌓이면 자연스럽게 최적화된다. 세팅을 완벽하게 하려다 정작 그림을 안 그리는 초보자가 많다. 지금은 50% 세팅으로 시작하는 게 정답이다.
