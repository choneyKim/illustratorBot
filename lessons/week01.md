## 1일차 (평일/3시간) — CSP 인터페이스 완전 정복

### 🎯 오늘의 목표
CSP의 모든 패널과 도구가 어디 있고 무슨 역할인지 파악한다. 모르는 버튼이 없는 상태로 만든다.

### 📖 CSP 인터페이스 구조

CSP를 처음 열면 이런 구조다:

```
┌─────────────────────────────────────────────┐
│  메뉴바 (파일/편집/레이어/필터...)           │
├──────┬──────────────────────────┬────────────┤
│      │                          │ 레이어 패널 │
│ 도구 │        캔버스             │ 컬러 패널  │
│ 팔레트│                          │ 서브 뷰    │
│      │                          │ 내비게이터  │
├──────┤                          ├────────────┤
│서브도구│                         │ 도구 속성  │
│팔레트 │                          │ 패널       │
└──────┴──────────────────────────┴────────────┘
```

**각 패널 설명:**

| 패널 | 위치 | 역할 |
|------|------|------|
| **도구 팔레트** | 왼쪽 세로 | 펜/지우개/선택/이동 등 주요 도구 선택 |
| **서브 도구 팔레트** | 왼쪽 도구 아래 | 선택한 도구의 세부 종류 (G펜, 연필 등) |
| **도구 속성 패널** | 오른쪽 하단 | 브러시 크기, 불투명도, 안정화 수치 |
| **레이어 패널** | 오른쪽 상단 | 레이어 목록, 추가/삭제/순서 변경 |
| **컬러 패널** | 오른쪽 중간 | 색상 선택 |
| **내비게이터** | 오른쪽 | 전체 캔버스 축소 미리보기 + 이동 |
| **서브 뷰** | 우하단 | 참고 이미지 고정해놓는 패널 |

**Galaxy Tab에서 패널이 안 보이면**: 메뉴바 → 윈도우 → 해당 패널 이름 체크

### 📖 캔버스 조작 — 가장 중요한 단축키들

프로 일러스트레이터가 하루에 수백 번 쓰는 조작이다. 몸에 익을 때까지 의식적으로 쓴다.

| 단축키 | 기능 | 왜 중요한가 |
|--------|------|------------|
| **H** | 좌우반전 (수평 플립) | ★★★ 선이 올바른지 확인하는 핵심 기법. 반전했을 때 삐뚤어 보이면 실제로 삐뚤어진 것. 프로들은 5분에 한 번 이상 누름. |
| **R** | 캔버스 회전 | 불편한 각도 선을 내가 편한 각도로 캔버스를 돌려서 그림. 선이 훨씬 깔끔해짐. |
| **스페이스** | 손바닥 도구(캔버스 이동) | 손바닥 도구로 전환해서 캔버스 드래그 이동. |
| **[ ]** | 브러시 크기 축소/확대 | 키보드 대괄호 키. 작업 중 브러시 크기 빠르게 바꿈. |
| **Ctrl+Z** | 실행취소 | 기본 중의 기본. |
| **Ctrl+Shift+Z** | 재실행 | 취소를 취소. |
| **Ctrl+T** | 변형 (Transform) | 그린 선/오브젝트 크기/위치/기울기 조절. |
| **Ctrl+Alt+드래그** | 브러시 크기 드래그 조절 | 캔버스에서 직접 드래그로 브러시 크기 실시간 조절. |
| **F** | 화면 맞추기 | 캔버스를 화면 크기에 꽉 차게 맞춤. 줌 리셋. |
| **G** | 채우기 도구 | 선택 영역이나 닫힌 영역을 색으로 채움. |
| **Alt+클릭** | 색상 스포이드 (색 추출) | 캔버스의 특정 색을 현재 색으로 선택. |
| **Tab** | UI 전체 숨기기/보이기 | 그림만 보고 싶을 때. |

> **좌우반전(H키)를 버릇으로 만들어라**: 선화를 그릴 때 우리 눈은 작업 방향에 익숙해져서 오류를 못 느낀다. 반전하면 뇌가 "새로운 이미지"로 인식해서 오류가 바로 보인다. 얼굴이 찌그러진 것, 눈 위치가 비대칭인 것이 반전 순간 바로 눈에 들어온다.

### 📖 CSP 회전 도구 제대로 쓰기

1. **단축키 R** → 캔버스가 회전 모드로 전환
2. 손가락 또는 S Pen으로 드래그 → 원하는 각도로 회전
3. **R 다시 누르거나 F** → 원래 각도로 복귀

왜 쓰냐: 위에서 아래로 내려긋는 선이 가장 안정적이다. 곡선이 불편한 방향이면 캔버스를 돌려서 편한 방향으로 긋는다.

### ✏️ 실습 순서

1. CSP 새 캔버스 생성: 2000×2000px, 72dpi (연습용)
2. 도구 팔레트 각 도구를 하나씩 눌러보며 서브 도구 목록 확인 (10분)
3. 단축키 연습:
   - H 키 5번 누르기 (반전되는 것 확인)
   - R 키로 캔버스 45도/90도/180도 회전해보기
   - F 키로 화면 맞추기
   - [ ] 로 브러시 크기 변화 확인
4. 캔버스에 자유롭게 선 그으면서 5분에 한 번 H 키 누르는 습관 연습

### 🖼️ 참고 이미지 키워드
`Clip Studio Paint interface tutorial` / `CSP workspace setup 2024`

### 📝 오늘의 과제
CSP에서 원 하나를 그린 후 — 좌우반전(H)했을 때 반전 전과 반전 후 스크린샷 두 장 제출. 반전 후 어떤 차이가 보이는지 짧게 설명 포함.

## 2일차 (평일/3시간) — 8BitDo + S Pen 단축키 시스템 구축

### 🎯 오늘의 목표
8BitDo 컨트롤러와 S Pen 버튼을 CSP 핵심 단축키에 매핑해서 키보드 없이 빠른 작업 환경 완성.

### 📖 8BitDo Galaxy Tab 연결 방법

**블루투스 페어링:**
1. 8BitDo 컨트롤러 전원 켜기
2. 페어링 모드 진입 (모델별 방법):
   - **Micro**: Y버튼 + START 동시에 길게 누름
   - **Zero 2**: SELECT + B 동시에 길게 누름
   - **SN30 Pro**: X + START 동시에 길게 누름
   - **Ultimate**: 뒷면 페어링 버튼 누름
   - LED가 빠르게 깜빡이면 페어링 대기 상태
3. Galaxy Tab → 설정 → 블루투스 → 스캔 → 8BitDo 선택 → 연결

**연결 확인**: Galaxy Tab 상단 바에 블루투스 아이콘 뜨면 성공

> **주의**: 처음 연결 시 "입력 기기 종류" 선택 창이 뜰 수 있음. **"키보드"** 또는 **"게임패드"** 선택. CSP 단축키 연동을 위해서는 키보드로 인식되어야 하는 경우도 있음.

### 📖 CSP에서 컨트롤러 단축키 설정

**경로**: CSP → 파일 → 단축키 설정 (또는 환경 설정 → 태블릿 → 외부 입력)

8BitDo 버튼을 CSP 단축키에 매핑하는 방법:
1. 단축키 설정 창 열기
2. 변경하려는 기능 찾기 (예: "좌우 반전")
3. 해당 행 더블클릭 또는 클릭 후 "단축키 편집"
4. 8BitDo에서 원하는 버튼 누르기 → 버튼 입력이 등록됨
5. 확인 → 저장

**권장 매핑 (참고, 손에 맞게 자유롭게 수정):**

| 8BitDo 버튼 | 추천 기능 | 단축키 |
|------------|---------|--------|
| **L1 (왼쪽 범퍼)** | 실행취소 | Ctrl+Z |
| **R1 (오른쪽 범퍼)** | 재실행 | Ctrl+Shift+Z |
| **L2 (왼쪽 트리거)** | 브러시 크기 축소 | [ |
| **R2 (오른쪽 트리거)** | 브러시 크기 확대 | ] |
| **위 D패드** | 좌우반전 | H |
| **아래 D패드** | 화면 맞추기 | F |
| **왼쪽 D패드** | 이전 레이어 | Page Up |
| **오른쪽 D패드** | 다음 레이어 | Page Down |
| **A버튼** | 색상 스포이드 | Alt+클릭 → Alt |
| **B버튼** | 지우개↔브러시 전환 | E |
| **X버튼** | 채우기 | G |
| **Y버튼** | 새 레이어 | Ctrl+Shift+N |
| **START** | 저장 | Ctrl+S |

> **팁**: 처음부터 다 외우려 하지 말 것. L1/R1 (취소/재실행)과 위D패드 (좌우반전)만 먼저 익히고, 나머지는 작업하면서 필요할 때 하나씩 추가.

### 📖 S Pen 버튼 설정

S Pen 버튼은 2가지 동작이 가능하다:
- **짧게 누름**: 도구 전환 (기본: 지우개 전환)
- **길게 누름**: 다른 기능

**설정 경로**: Galaxy 설정 → 고급 기능 → S Pen → S Pen 동작 → 버튼을 누른 상태로 동작

**권장 설정:**
- 짧게 누름: **지우개 전환** (브러시와 지우개 즉시 전환)
- 길게 누름: **실행취소** (또는 퀵 노트 비활성화)

**CSP 퀵 액세스 팔레트:**
CSP 자체의 원형 메뉴. 등록된 도구를 화면 어디서나 꺼낼 수 있음.
- 설정: 보기 → 퀵 액세스 → 퀵 액세스 설정
- 추천 등록: 브러시, 지우개, 선택, 채우기, 변형, 레이어 신규

### ✏️ 실습 순서

1. 8BitDo 블루투스 연결 완료
2. CSP 단축키 설정에서 L1=취소, R1=재실행, 위D패드=좌우반전 최소한 3개만 먼저 설정
3. S Pen 버튼 짧게 누름 = 지우개 전환 설정
4. 새 캔버스에서 30분간 그림 그리면서 컨트롤러/S Pen 단축키만 사용해보기
5. 불편한 점 메모 → 필요하면 매핑 수정

### 📝 오늘의 과제
8BitDo 연결 완료 + 설정한 단축키 매핑표 (버튼-기능) 스크린샷 또는 직접 작성해서 제출.
컨트롤러/S Pen만으로 10분 드로잉한 결과물도 함께.

## 3일차 (평일/3시간) — 레이어 시스템 완전 정복

### 🎯 오늘의 목표
프로 일러스트레이터의 레이어 구조를 이해하고, 처음부터 제대로 된 파일 구조로 작업하는 습관을 만든다.

### 📖 레이어란 무엇인가

레이어는 투명한 셀로판 필름을 겹쳐 놓은 것이다. 각 필름에 따로 그리기 때문에 한 레이어를 수정해도 다른 레이어는 영향을 안 받는다.

**레이어 없이 그리면**: 선화와 채색이 합쳐져서 나중에 수정 불가. 선을 지우면 채색도 같이 지워짐.

**레이어를 제대로 쓰면**: 선화 유지한 채 채색만 수정 가능. 그림자만 따로 조정 가능.

### 📖 프로 일러스트레이터 레이어 구조

```
[폴더] 이펙트/후보정
  └─ 색조 보정 레이어들

[폴더] 배경
  └─ 배경 레이어들

[폴더] 캐릭터
  ├─ [레이어] 선화           ← 가장 위
  ├─ [폴더] 채색
  │    ├─ [레이어] 하이라이트
  │    ├─ [레이어] 그림자2
  │    ├─ [레이어] 그림자1
  │    ├─ [레이어] 피부 플랫
  │    ├─ [레이어] 머리카락 플랫
  │    ├─ [레이어] 눈 플랫
  │    └─ [레이어] 의상 플랫
  └─ [레이어] 밑그림         ← 가장 아래 (작업 후 숨김)
```

**핵심 레이어 설정들:**

**클리핑 마스크 (Clipping Mask)**
- 아래 레이어의 형태 안에만 그려지게 하는 기능
- 채색할 때 선 밖으로 삐져나갈 걱정 없음
- 설정: 레이어 → 아래 레이어에 클리핑 (단축키: Ctrl+Alt+G)
- 레이어 왼쪽에 빨간 꺾쇠(↙) 아이콘이 붙으면 클리핑 상태

**기준 레이어 (Reference Layer)**
- 이 레이어의 선을 기준으로 채우기 도구가 인식함
- 선화 레이어에 설정해두면 다른 레이어에서 채우기해도 선 안으로만 채워짐
- 설정: 레이어 속성 패널에서 등대 모양 아이콘 클릭

**레이어 합성 모드 (Blending Mode)**
- 레이어가 아래 레이어와 합쳐지는 방식
- **곱하기(Multiply)**: 그림자 레이어에 사용. 아래 색과 곱해져 어두워짐
- **스크린(Screen)**: 하이라이트에 사용. 밝아짐
- **오버레이(Overlay)**: 색감 보정에 사용. 대비와 채도 증가

### 📖 CSP 레이어 단축키

| 동작 | 단축키 |
|------|--------|
| 새 레이어 | Ctrl+Shift+N |
| 레이어 복제 | Ctrl+C → Ctrl+V 또는 레이어 패널에서 드래그 |
| 레이어 아래로 병합 | Ctrl+E |
| 전체 표시 레이어 병합 | Ctrl+Shift+E |
| 레이어 불투명도 | 레이어 패널 상단 슬라이더 |
| 클리핑 마스크 | Ctrl+Alt+G |

### ✏️ 실습 순서

1. 새 캔버스 생성
2. 위의 레이어 구조 그대로 폴더/레이어 만들기 (이름까지 똑같이)
3. 밑그림 레이어에 간단한 원 캐릭터 러프 스케치
4. 선화 레이어에 선 따기 연습
5. 피부 플랫 레이어에 클리핑 마스크 설정 후 채색 → 선 밖으로 안 나가는지 확인
6. 이 레이어 구조를 CSP 템플릿으로 저장:
   파일 → 다른 이름으로 저장 → 저장 위치를 CSP 템플릿 폴더 선택

### 📝 오늘의 과제
완성된 레이어 구조 스크린샷 제출 (폴더/레이어 이름 모두 보이게). 클리핑 마스크 테스트 결과(채색이 선 안에만 있는 것) 포함.

## 4일차 (평일/3시간) — 브러시 과학: 선화 품질은 브러시에서 결정된다

### 🎯 오늘의 목표
애니 스타일 선화에 최적화된 브러시 세팅을 이해하고, 나만의 커스텀 브러시 완성.

### 📖 브러시 설정 완전 해설

CSP 브러시 설정 경로: 서브 도구 팔레트에서 브러시 더블클릭 → 서브 도구 상세

**브러시 크기**
- 기본 크기: 선화용 5~10px (A4 기준)
- 최소 크기: 5~10% (필압 가볍게 누를 때 선이 너무 얇아지지 않도록)
- Galaxy Tab S Pen은 필압 4096레벨이므로 세밀한 조절 가능

**필압 설정 (필압 → 크기)**
그래프 모양으로 설정. 가로축=필압, 세로축=브러시 크기.
- **권장 곡선**: S자 형태. 약하게 누를 때 = 가늘게, 강하게 누를 때 = 굵게. 중간 영역이 넓어야 자연스러운 선.
- 너무 가파른 곡선 = 필압에 너무 민감, 선이 불안정
- 너무 완만한 곡선 = 필압 차이가 안 느껴짐

**손떨림 보정 (안정화)**
- 수치: 0~100. 높을수록 선이 부드러워지지만 반응이 느려짐
- **권장**: 10~20 (너무 높으면 빠른 선을 그을 때 원하는 방향으로 안 감)
- 종류: 후보정 / 벡터 안정화가 있음. 선화용으로는 **후보정** 권장

**불투명도 설정**
- 선화용: **100% 고정** (필압에 따라 변하면 선이 흐릿해짐)
- 채색용 에어브러시: 30~60% (자연스러운 블렌딩)

### 📖 선화용 브러시 추천 설정

**G펜 기반 커스텀 (애니 선화 표준):**
```
브러시 크기: 7~8px (기준, 작업 중 [ ]로 조절)
최소 크기: 8%
필압→크기: S자 곡선
손떨림 보정(후보정): 15
불투명도: 100% (필압 영향 없음)
필압→불투명도: 비활성화
잉크 흡수: 없음
```

**실제로 차이 나는 설정: 잉크 흐름(Ink flow) / 아웃라인**
- **잉크 흐름 없음**: 처음부터 끝까지 동일한 농도 → 균일한 선화
- 잉크 흐름 있음: 그리다 보면 점점 진해짐 → 연필 느낌

### 📖 S Pen 필압 캘리브레이션

CSP 자체 필압 설정: 파일 → 환경설정 → 태블릿 → 필압 조정

1. 캘리브레이션 창 열기
2. "가벼운 힘으로 그리기" 지시에 따라 가볍게 선 긋기
3. "보통 힘으로 그리기" 지시에 따라 보통 힘으로 선 긋기
4. 자동으로 필압 곡선 최적화
5. 결과 확인: 가볍게 누르면 얇은 선, 세게 누르면 굵은 선이 나와야 함

### ✏️ 실습 순서

1. G펜 브러시 복제 (원본 보존): 서브 도구 팔레트에서 우클릭 → 복사
2. 복사한 브러시 위 설정값으로 커스터마이즈
3. S Pen 필압 캘리브레이션 실행
4. 브러시 테스트:
   - 가장 가볍게 누른 선 ~ 가장 세게 누른 선을 나란히 그어보기
   - 선 굵기 차이 확인 (얇은 선: 0.5~1px / 두꺼운 선: 5~8px)
5. 만족스러우면 브러시 이름 "선화용_메인"으로 저장
6. 8BitDo L2/R2 = 브러시 크기 축소/확대 확인

### 📝 오늘의 과제
커스텀 선화 브러시로 그린 선 테스트 시트 제출:
- 가장 가벼운 선 / 보통 선 / 가장 강한 선 3단계 비교
- 직선 10개 + 곡선 10개 (선의 강약 확인 목적)
- 브러시 설정 스크린샷 포함

## 5일차 (평일/3시간) — 캔버스 설정 & 파일 관리 워크플로우

### 🎯 오늘의 목표
작업 목적에 맞는 캔버스 설정 + 저장/내보내기 습관 완성. 파일 관리로 나중에 찾아보기 편하게.

### 📖 캔버스 설정 — 무엇이 중요한가

**해상도(dpi) 선택 기준:**
- **72dpi**: 화면 표시용 (SNS, 디지털 전용). 파일 작고 빠름. 인쇄 불가.
- **150dpi**: 중간. 작은 인쇄물 가능.
- **350dpi**: 인쇄용 표준. 파일 크고 무거움.

Galaxy Tab S11 Ultra에서 권장:
- 연습용 드로잉: **1500×1500px, 72dpi** (빠르고 가벼움)
- 완성 일러스트: **3000×4000px, 150dpi** (품질 좋고 Galaxy Tab 성능에 적합)
- 고품질 완성작: **4000×5500px, 350dpi** (무겁지만 최고 품질)

> 해상도를 높이면 파일이 커지고 Galaxy Tab이 버벅일 수 있다. 처음엔 150dpi로 시작하고, 기기 성능 확인 후 올린다.

**컬러 모드:**
- **RGB**: 디지털 화면 표시용. 선명하고 밝은 색 가능. 우리 목표는 이것.
- CMYK: 인쇄용. 색이 어둡고 탁하게 보임.

### 📖 파일 형식 이해

| 형식 | 특징 | 언제 쓰나 |
|------|------|----------|
| **.clip** | CSP 전용 원본. 모든 레이어 보존. | 작업 중 저장, 나중에 수정할 파일 |
| **.png** | 투명 배경 지원. 고품질. | 완성작 제출/공유. 선화 단독 저장. |
| **.jpg** | 배경 있음. 파일 작음. | 배경 있는 완성작 SNS 업로드. |
| **.psd** | Photoshop 형식. 레이어 일부 유지. | Photoshop에서 추가 작업할 때. |

### 📖 저장 습관 — 이것만 지켜라

**작업 중 자동 저장 설정:**
환경설정 → 파일 → 자동 저장 → 간격: 10분

**파일 이름 규칙:**
```
YYYY-MM-DD_W01D05_내용.clip
예: 2026-04-16_W01D05_브러시테스트.clip
```

**폴더 구조:**
```
D:/illustratorBot/works/
├── practice/          (연습용)
│   ├── week01/
│   ├── week02/
│   └── ...
└── completed/         (완성작)
    ├── 2026-04-12_첫완성작.png
    └── ...
```

**내보내기 워크플로우 (완성 시):**
1. 파일 → 화상을 통합하여 내보내기 → PNG 선택
2. 해상도: 원본 유지
3. 저장: `D:/illustratorBot/works/completed/`

### ✏️ 실습 순서

1. 위 폴더 구조 직접 만들기 (Windows 탐색기에서)
2. 연습용 캔버스 (1500px, 72dpi) + 완성작용 캔버스 (3000px, 150dpi) 각각 만들어보기
3. 자동 저장 설정 (10분 간격)
4. 3일차에 만든 레이어 구조 파일을 규칙에 맞게 이름 저장
5. PNG로 내보내기 연습

### 📝 오늘의 과제
1~5일차 작업물 중 하나를 PNG로 내보낸 파일 제출 + 본인이 정한 파일 관리 규칙 (이름 형식, 폴더 구조) 설명

## 6일차 (주말/4시간) — 주말 실습: 환경 완성 점검 + 선 연습 입문

### 🎯 오늘의 목표
1~5일차 설정 전체 재점검 + 선 연습 첫 진지한 시도. 다음 주를 위한 준비.

### 📖 좌우반전으로 선 품질 체크하는 법

오늘부터 모든 드로잉에서 이 루틴을 습관화한다:

1. 선 10~20개 긋기
2. **H키** 눌러서 좌우반전
3. 비뚤어진 선, 흔들린 선 확인
4. H키 다시 눌러서 원상복귀
5. 발견한 문제 부분 다시 그리기

### 📖 선을 잘 긋는 원리

**팔꿈치를 축으로**: 손목만 쓰면 짧은 선밖에 못 그음. 긴 선은 팔꿈치를 축으로 팔 전체가 움직여야 함.

**속도가 품질을 만든다**: 천천히 조심조심 그은 선은 반드시 떨린다. 자신 있게 빠르게 그어야 깔끔하다. 처음엔 이상하게 느껴지지만 연습하면 정확도도 올라간다.

**가이드 점 찍기**: 긴 선을 긋기 전에 시작점과 끝점을 먼저 가볍게 점으로 찍어두고, 그 두 점을 잇는 선을 그으면 훨씬 정확해진다.

### ✏️ 실습 순서

1. 환경 점검 체크리스트:
   - [ ] 8BitDo 연결 및 단축키 작동
   - [ ] S Pen 버튼 설정
   - [ ] 선화용 브러시 즐겨찾기 등록
   - [ ] 레이어 템플릿 저장
   - [ ] H키 좌우반전 습관 확인

2. 선 연습 (총 2시간):
   - 수평선 50개 (가이드 점 없이) → H키로 확인
   - 수직선 50개 → H키로 확인
   - 사선 (45도) 50개 → H키로 확인
   - 처음 50개 vs 마지막 50개 비교

3. 스타레일/명조 캐릭터 실루엣 트레이싱 (1시간):
   - 원본 이미지를 서브 뷰 패널에 고정
   - 선화만 따라 그리기 (채색 없이)
   - 작업 중 H키로 3회 이상 확인

### 📝 오늘의 과제
선 연습 시트 제출 (수평/수직/사선 각 50개). 처음 50개와 마지막 50개의 차이가 보여야 통과.

이번 주 익힌 환경에서 자유롭게 그리면서 익숙해지기. 다음 주 선 제어를 위한 현재 실력 파악.
