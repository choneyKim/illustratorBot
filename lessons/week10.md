# 10주차 — 플랫 채색 워크플로우

**주간 목표**: CSP에서 깔끔한 플랫 채색 완성 + 채색 레이어 구조 체계화

---

## 1일차 (평일/3시간) — 채색 워크플로우 세팅

### 🎯 오늘의 목표
CSP 채색 도구 이해 + 깔끔한 플랫 채색 방법 숙지

### 📖 이론 & 설명
플랫 채색 방법 (CSP 기준):
1. 선화 레이어 위에 채색 폴더 생성
2. 채색 폴더에 클리핑 마스크 설정
3. 부위별 레이어 (피부/머리카락/의상/눈 등) 분리
4. 각 레이어에 "채우기"로 기본색 입힘

깔끔하게 채색하는 팁:
- 선화 레이어를 "기준 레이어"로 설정 → 선 안으로만 채워짐
- 경계 침범 부분은 선택 범위 도구로 수정

### ✏️ 실습 순서
1. 간단한 캐릭터 선화 준비 (얼굴+상반신)
2. 위 채색 레이어 구조 그대로 만들기
3. 피부색 → 머리카락 → 의상 순서로 플랫 채색
4. 삐져나온 부분 수정

### 📝 오늘의 과제
플랫 채색 완성 반신 캐릭터 제출 (레이어 구조 스크린샷 포함)

⏱️ 예상 시간: 평일 3시간

## 2일차 (평일/3시간) — 색상 선택 이론

### 🎯 오늘의 목표
스타레일/명조 스타일 컬러 팔레트 이해

### 📖 이론 & 설명
색상 조화 기본:
- **유사색**: 인접한 색끼리 (편안하고 조화로운 느낌)
- **보색**: 반대편 색 (강렬하고 대비되는 느낌)
- **3색 조화**: 삼각형 위치 색 (밸런스 좋음)

스타레일 팔레트 특징: 채도가 중간~높음, 명도 차이로 입체감 표현, 의상과 눈 색이 연관됨.

### ✏️ 실습 순서
1. CSP 색상환에서 유사색/보색 조합 찾기
2. 스타레일 캐릭터 3명의 색상 팔레트 추출 (스포이드)
3. 추출한 팔레트로 캐릭터 재채색

### 📝 오늘의 과제
스타레일 캐릭터 1명 팔레트 추출 + 해당 팔레트로 오리지널 캐릭터 채색 제출

⏱️ 예상 시간: 평일 3시간

### 🎯 오늘의 목표

### 📖 이론 & 설명
피부 기본색 선택: 너무 노랗거나 너무 핑크하지 않은 크림색 계열.
뺨 홍조: 에어브러시로 살짝 핑크/오렌지를 눈 아래 뺨에 원형으로.

### 📝 오늘의 과제

⏱️ 예상 시간: 평일 3시간

### 🎯 오늘의 목표

### 📖 이론 & 설명
머리카락은 단일색보다 메인색 + 보조색(1~2가지 유사색)을 쓰면 훨씬 생동감 있다. 앞머리/뒷머리/강조 부분을 살짝 다른 색으로.

### 📝 오늘의 과제

⏱️ 예상 시간: 평일 3시간
