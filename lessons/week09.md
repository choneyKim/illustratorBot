# 9주차 — 의상과 천 표현

**주간 목표**: 의상 주름의 원리 이해 + 스타레일/명조 스타일 코스튬 디테일

---

## 1일차 (평일/3시간) — 주름의 원리

### 🎯 오늘의 목표
당기는 힘과 걸리는 힘으로 주름 예측하기

### 📖 이론 & 설명
주름은 항상 고정점(pin)에서 시작한다. 어깨가 고정점이면 주름이 어깨에서 사방으로 퍼진다. 중력도 주름을 만든다(아래로 처짐).

주름 유형:
- **지퍼 주름**: 당기는 방향으로 모여드는 선
- **파이프 주름**: 원통이 접힌 것처럼 (바지 무릎, 소매)
- **흘러내림 주름**: 중력으로 자연스럽게 처짐
- **디아고날 주름**: 대각선으로 당겨지는 주름

### ✏️ 실습 순서
1. 각 주름 유형 5개씩 연습
2. 흰 천을 다양한 방식으로 잡고 사진 찍어보기 (없으면 구글 이미지)
3. 스타레일 캐릭터 의상 주름 분석

### 📝 오늘의 과제
주름 유형 4종 연습 시트 제출

⏱️ 예상 시간: 평일 3시간

## 4일차 (평일/3시간) — 스타레일/명조 코스튬 분석

### 🎯 오늘의 목표
스타레일/명조 캐릭터 의상 디테일 분석 + 재현

### 📖 이론 & 설명
스타레일/명조 의상의 특징:
- 동양풍 디테일 (비단 느낌, 문양, 레이어드 의상)
- 과감한 노출과 화려한 장식의 조화
- 금속 장식구/보석 디테일

### ✏️ 실습 순서
1. 좋아하는 스타레일/명조 캐릭터 의상 1개 선택
2. 의상 구성 요소 분해 (상의/하의/장식)
3. 의상만 트레이싱 (인체 제외)
4. 주름 위치와 방향 분석

### 📝 오늘의 과제
의상 트레이싱 + 구성 요소 레이블 포함 제출

⏱️ 예상 시간: 평일 3시간
