✏️ 실습 순서
1
패널 6개 직접 찾기 (30분)
각 패널 클릭해서 실제 위치 확인. 없으면 메뉴바 → 윈도우 → 체크.
2
단축키 7개 손에 익히기 (1시간)
파일 → 신규 → A4, 350dpi, RGB. H/R/Space/[/]/F/Ctrl+Z 각 10번씩.
3
브러시 3종 비교 (30분)
G펜 / 연필 / 에어브러시 각각 선 5개씩. 굵기·텍스처·끝 처리 차이 확인.
4
레이어 구조 연습 (1시간)
레이어 3개 만들기 → 각각 다른 브러시로 선 → 순서 바꾸기 → 눈 아이콘·이름 변경·삭제.

📝 과제
레이어 3개 생성 + 각 레이어에 G펜/연필/에어브러시로 선 그리기 → 레이어 패널 보이는 전체 화면 캡처 + H키 반전 화면 제출.
✅ 합격 기준
  • 레이어 3개 이상
  • 브러시별 선 차이 보임
  • 레이어 이름 지정됨
  • H키 반전 화면 포함
🎯 2일차 목표
선화에 최적화된 브러시 세팅 완성. 채색용 브러시도 별도 세팅. 8BitDo S Pen 버튼 등록.
📖 선화용 브러시 세팅 핵심
🖌️ CSP 펜 설정 및 안정화 세팅
출처: clipstudio.net

선화용 브러시 권장 세팅:

  • 브러시: G펜 또는 밀리펜
  • 안정화(Stabilizer): 10~20 (너무 높으면 반응 느려짐)
  • 필압 설정: 시작·끝 가늘게 (S자 커브)
  • 불투명도: 100%
💡 Galaxy Tab S Pen 팁: 도구 속성 패널 → 필압 보정에서 본인 손 힘에 맞게 조정. 처음엔 안정화 15로 시작.
✏️ 실습 순서
1
선화용 브러시 세팅 (1시간)
G펜 복제 → 이름 "선화용"으로 변경 → 안정화 15, 필압 S커브 설정.
2
채색용 브러시 세팅 (30분)
수채화 브러시 복제 → "채색용" → 불투명도 80%, 경도 낮게.
3
S Pen 버튼 / 8BitDo 단축키 등록 (1시간)
파일 → 단축키 설정 → H, R, [, ] 8BitDo 버튼에 할당. S Pen 버튼: Ctrl+Z 설정.
4
퀵 액세스 팔레트 구성 (30분)
자주 쓰는 도구 4~6개를 퀵 액세스에 추가.
📝 과제
완성된 브러시 세팅 화면 스크린샷 + 세팅한 브러시로 선 10개 그어서 제출.
🎯 3일차 목표
레이어를 목적에 맞게 분리하는 습관 만들기. 폴더 구조로 작업 파일 정리.
📖 레이어 구조 관리
🗂️ CSP 서브 도구 / 레이어 관리
출처: gvaat.com

일러스트 레이어 기본 구조:

  • 📁 완성 (최상단)
  •   └ 효과/이펙트
  • 📁 채색
  •   └ 의상 / 헤어 / 피부 / 눈
  • 선화 (기준 레이어 설정)
  • 📁 밑그림
  •   └ 러프
✏️ 실습 순서
1
위 레이어 구조 그대로 만들기 (1시간)
빈 캔버스에 폴더 + 레이어 구조 세팅. 이름 한글로 지정.
2
클리핑 마스크 연습 (1시간)
피부 레이어 위에 새 레이어 → 클리핑 마스크 → 피부 영역 밖으로 안 나가는 것 확인.
3
레이어 세팅 저장 (1시간)
완성된 구조를 .csp 파일로 저장 → 앞으로 매 작업 시작할 때 이 파일 복사해서 쓰기.
📝 과제
레이어 폴더 구조 완성된 CSP 화면 스크린샷 제출.
🎯 4일차 목표
일러스트에 최적화된 캔버스 설정과 일관된 작업 흐름 확립.
📖 캔버스 설정 & 작업 흐름
설정 항목권장값이유
캔버스 크기2894×4093 (A4)인쇄·SNS 모두 대응
해상도350dpi인쇄 품질 보장
컬러 모드RGB디지털 작업 기본
기본 표현색컬러채색 작업 기준
💡 작업 시작 루틴: ① 캔버스 열기 → ② H키 습관 들이기 → ③ 레이어 구조 확인 → ④ 러프 시작
✏️ 실습 순서
1
캔버스 설정 최적화 (1시간)
2
작업 흐름 1회 전체 연습 (2시간)
러프 → 선화 → 채색 레이어 구조로 간단한 얼굴 1개 그려보기.
📝 과제
작업 흐름대로 완성한 간단한 얼굴 선화 1개 제출 (레이어 구조 보이는 스크린샷 포함).
🎯 5일차 목표
1주차에 배운 모든 환경 설정을 실전처럼 종합 연습한다.
✏️ 실습 순서
1
작업 루틴 처음부터 끝까지 (3시간)
① 새 캔버스 → ② 레이어 구조 세팅 → ③ 브러시 확인 → ④ 러프 → ⑤ 선화 → ⑥ 저장
단축키 최대한 활용. 마우스·메뉴 최소화.
📝 과제
1주차 환경 세팅 완성본 스크린샷 제출. 브러시 세팅 + 레이어 구조 + 단축키 설정 화면 모두 포함.
🎯 6일차 목표 (주말)
환경 점검 + 선 연습 첫 경험. 내 손이 선을 어떻게 긋는지 파악한다.
✏️ 실습 순서
1
환경 점검 (30분)
브러시 세팅, 레이어 구조, 단축키 — 모두 작동하는지 확인.
2
선 연습 입문 (3시간 30분)
빈 캔버스에 직선 50개 → 곡선 50개 → H키로 확인 반복.
목적: 완성도 아님. 지금 내 선 수준 파악이 목적.
📝 과제
선 연습 캔버스 스크린샷 제출 (잘 그리지 않아도 됨 — 현재 실력 파악용).
🎯 7일차 목표 (주말)
자유 창작 — 배운 도구로 그리고 싶은 것 마음껏 그리기.
✏️ 실습 순서
1
자유 드로잉 (4시간)
주제 없음. 그리고 싶은 것 뭐든 OK. H키 습관만 유지.
📝 과제
자유 창작 결과물 1장 제출 (완성도 무관).
