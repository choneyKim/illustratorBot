# 2주차 — 선 제어 집중 훈련

**주간 목표**: 어떤 방향이든, 어떤 길이든 원하는 선을 원하는 자리에 긋는 능력 습득.
**핵심 원칙**: 선 품질은 속도에서 나온다. 느리게 그을수록 선은 떨린다.

---

## 1일차 (평일/3시간) — 직선 마스터

### 🎯 오늘의 목표
어떤 방향의 직선도 가이드 없이 일필휘지로 긋기. 선의 시작과 끝을 컨트롤하기.

### 📖 선 하나에 담기는 정보

애니 선화에서 선 하나는 단순한 경계가 아니다. 좋은 선에는:

- **방향감**: 어디서 어디로 향하는지가 명확
- **속도감**: 선이 멈추지 않고 흘러가는 느낌
- **강약**: 시작·중간·끝의 굵기 변화로 생동감 표현
- **자신감**: 망설임이 없는 일필

**"입필 → 질주 → 발필" 3단계:**
1. **입필**: 시작점에 S Pen을 살짝 눌러 얇게 시작
2. **질주**: 빠르게 선을 그으면서 압력 유지
3. **발필**: 끝점에서 S Pen을 들어올리며 선 마무리 (얇아지며 끝)

이 3단계를 의식하지 않아도 자동으로 될 때까지 반복이 필요하다.

### 📖 선을 잘 못 긋는 이유 TOP 3

**1위. 손목만 쓴다**
손목 관절을 축으로 그으면 짧은 원호만 나온다. 긴 직선은 팔꿈치 또는 어깨를 축으로 팔 전체가 움직여야 한다. 지금 팔꿈치를 책상에서 들고 팔 전체로 선을 그어보라. 훨씬 안정적이다.

**2위. 너무 천천히 긋는다**
천천히 = 손 떨림이 고스란히 기록됨. 무서워도 빠르게 그어야 한다. 처음엔 위치가 틀려도 된다. 위치는 연습으로 잡히지만 속도는 의식하지 않으면 절대 안 붙는다.

**3위. 캔버스 각도를 고정한다**
불편한 방향의 선을 억지로 그으려 하지 마라. **캔버스를 회전(R키)** 해서 내가 편한 방향(보통 위에서 아래로 내려긋기)으로 바꾸면 모든 방향의 선이 편해진다.

### ✏️ 실습 순서

**준비**: 2000×2000px 캔버스, 선화용 브러시, 8BitDo 셋업 확인

**Round 1 — 가이드 점 있는 선 (1시간)**
1. 캔버스에 A4 크기로 두 점을 찍는다 (시작점, 끝점)
2. 그 두 점을 잇는 선을 일필로 긋기 × 50회
3. 매 10회마다 H키로 확인 → 비뚤어진 것 파악

**Round 2 — 방향별 선 (1시간)**
각 방향 30개씩, 캔버스 회전 적극 활용:
- 수평선 30개
- 수직선 30개
- 45도 사선 30개
- 각도 회전 후 불편한 방향 30개

**Round 3 — 강약 있는 선 (1시간)**
선의 입필-질주-발필 의식하며:
- 양 끝이 뾰족하고 가운데가 굵은 선 30개
- 한쪽만 뾰족한 선 30개 (왼쪽 뾰족, 오른쪽 뾰족 각 15개)

**각 라운드 후 H키로 확인 필수**

### 🖼️ 참고 이미지 키워드
`line control practice digital art` / `anime linework technique`

### 📝 오늘의 과제
강약 있는 선 연습 시트 제출. 처음 10개와 마지막 10개의 차이가 눈에 보여야 통과.

## 2일차 (평일/3시간) — 곡선 마스터

### 🎯 오늘의 목표
C곡선, S곡선, 원, 타원을 정확하고 자신 있게 그리기. 원 그리기 능력은 두상 구조로 직결된다.

### 📖 곡선이 직선보다 어려운 이유

직선은 방향만 일정하면 된다. 곡선은 **방향이 지속적으로 변하면서도 전체 흐름이 자연스러워야** 한다. 뇌가 더 많은 정보를 실시간으로 처리해야 한다.

**원 그리기의 비밀**: 팔꿈치를 축으로 팔 전체를 회전시키는 느낌. 손목이 아니다. 처음엔 크게 그리다가 점점 작게. 작은 원은 손목, 큰 원은 팔꿈치.

**S자 곡선은 두 방향이 이어진 것**: S자를 하나의 선으로 보지 말고, C자 두 개가 방향을 바꿔 이어진 것으로 본다. 방향 전환 지점에서 속도를 살짝 늦추는 것이 포인트.

### 📖 애니 선화에서 곡선의 역할

캐릭터 윤곽선: 거의 전부 곡선
머리카락: S자와 C자의 반복
얼굴형: 부드러운 타원에서 출발
눈: 위 눈꺼풀은 완만한 아치 곡선
턱 라인: C자 곡선

즉, **곡선을 못 그리면 캐릭터를 그릴 수 없다.** 이번 주 가장 중요한 훈련이다.

### ✏️ 실습 순서

**C곡선 훈련 (45분)**
- 작은 C (지름 1~2cm 정도) × 30개
- 중간 C × 30개
- 큰 C (캔버스 절반 크기) × 20개
- 좌향 C, 우향 C, 위향 C, 아래향 C 각 15개

**S곡선 훈련 (30분)**
- S자 30개 (유려하게, 두 곡선의 크기가 비슷하게)
- 반대 S자 (Z자 형태) 30개

**원 훈련 (45분)**
- 큰 원 (캔버스 절반) × 20개
- 중간 원 × 30개
- 작은 원 × 30개
- 매 10개마다 H키로 좌우 대칭 확인

**타원 훈련 (30분)**
- 가로 타원 20개
- 세로 타원 20개
- 기울어진 타원 20개

**매 세트 후 H키 확인 필수**

### 📝 오늘의 과제
원 연습 20개 + S곡선 10개를 하나의 시트에 담아 제출. 원이 얼마나 동그랗게 됐는지, S곡선이 얼마나 유려한지 확인.

## 3일차 (평일/3시간) — 선의 굵기와 정보: 애니 선화의 핵심 규칙

### 🎯 오늘의 목표
선 굵기의 차이만으로 평면적인 그림을 입체적으로 만드는 애니 선화 기법 습득.

### 📖 애니 선화의 굵기 규칙

이것이 "그냥 선 그린 것"과 "애니 선화"를 가르는 핵심이다:

**규칙 1: 외곽선 > 내부선**
캐릭터와 배경의 경계(외곽선)은 가장 굵게. 캐릭터 내부 선(옷 주름, 얼굴 세부)은 얇게. 이것만 지켜도 애니 느낌이 확 난다.

**규칙 2: 아래에 있을수록 굵게**
빛이 위에서 오면 위는 얇고 아래(그림자 쪽)는 굵다. 코 아래, 턱 아래, 옷 주름 아래가 굵어야 입체감이 생긴다.

**규칙 3: 강조 부분은 굵게**
눈 윗 눈꺼풀, 머리카락 끝, 손가락 관절 등 시선이 집중되는 곳은 굵게.

**규칙 4: 겹쳐지는 곳은 굵게**
앞에 있는 것이 뒤에 있는 것 위에 올 때, 겹치는 경계선을 굵게 그으면 원근감이 생긴다.

### 📖 CSP에서 선 굵기 바꾸는 방법

**방법 1: 8BitDo L2/R2로 브러시 크기 실시간 변경**
가장 빠름. 작업 흐름을 끊지 않고 굵기 변경 가능.

**방법 2: [ ] 단축키**
[ = 크기 감소, ] = 크기 증가. 약간씩 단계별로 변경.

**방법 3: 필압으로 자연스럽게**
브러시 설정이 잘 되어 있으면 필압만으로도 굵기 자연스럽게 변화.

**방법 4: 선 후보정 (그린 후 수정)**
이미 그린 선을 선택 → 레이어 → 선화 레이어 표시 변환 → 굵기 수정
단, 번거로우므로 처음부터 굵기 의식해서 그리는 것이 좋음.

### ✏️ 실습 순서

1. 외곽선/내부선 차이 연습:
   - 단순한 박스 하나를 그린다
   - 외곽: 8px 굵은 선
   - 내부에 디테일(선 하나 추가): 3px 얇은 선
   - H키로 확인

2. 트레이싱 실습 — 굵기 의식하며:
   - 스타레일 캐릭터 이미지를 서브 뷰에 고정
   - 외곽선만 먼저 굵게 따라 그리기
   - 내부 디테일 얇게 추가
   - 원본과 자신의 선화 H키 확인 비교

3. 테스트: 같은 캐릭터를 두 번 그리기
   - 버전 A: 모든 선 같은 굵기
   - 버전 B: 외곽 굵게, 내부 얇게
   - 두 버전 나란히 놓고 차이 비교

### 📝 오늘의 과제
버전 A (균일한 굵기)와 버전 B (굵기 차이 적용) 비교 이미지 제출. 어느 쪽이 더 입체적으로 보이는지 짧게 설명.

## 4일차 (평일/3시간) — 머리카락 선화 집중

### 🎯 오늘의 목표
애니 스타일 머리카락 선화의 흐름과 덩어리 개념 습득. 스타레일 스타일 머리카락 재현.

### 📖 머리카락 선화의 원리

**잘못된 생각**: 머리카락을 한 올씩 그린다
**올바른 방법**: 덩어리(뭉치)를 먼저 잡고, 그 안에 흐름선을 넣는다

**단계:**
1. **덩어리 실루엣**: 전체 머리카락의 큰 덩어리 3~5개를 실루엣으로 먼저 잡는다
2. **흐름선**: 덩어리 안에 흐름을 나타내는 주요 선 2~3개
3. **가닥 디테일**: 마지막에 가는 선으로 세부 가닥 추가 (선이 모두 같은 방향으로 흐름)

**스타레일/명조 머리카락 특징:**
- 큰 덩어리 중심, 세세한 가닥이 많지 않음
- 앞머리가 이마에서 약간 떠 있음 (공간감)
- 끝이 뾰족하게 마무리됨 (필압 점점 약하게)
- 머리카락이 겹치는 부분: 앞에 있는 가닥의 외곽선이 굵게

### 📖 덩어리 선화 그리는 순서

**앞머리:**
1. 헤어라인에서 내려오는 전체 앞머리 실루엣 C자 곡선으로
2. 이마와 앞머리 사이 공간 확보 (바짝 붙이지 말 것)
3. 앞머리 끝이 뾰족하게 마무리

**옆머리:**
1. 귀 위에서 아래로 흘러내리는 덩어리
2. 흐름 방향 통일 (보통 얼굴 방향쪽으로)

**뒷머리:**
1. 가장 큰 덩어리, 두상 전체를 감싸는 실루엣
2. 중력에 따라 아래로 흐르는 방향

### ✏️ 실습 순서

1. 덩어리 실루엣 연습:
   - 앞머리 덩어리 (바나나 모양) × 10개
   - 뒷머리 덩어리 실루엣 × 10개
   
2. 흐름선 추가 연습:
   - 덩어리 안에 같은 방향으로 흐르는 선 3~5개 추가 × 10세트

3. 뾰족한 끝 표현 연습:
   - 머리카락 끝: 선을 그으면서 필압을 점점 약하게 → 뾰족하게 마무리 × 30개

4. 스타레일 캐릭터 머리카락만 트레이싱:
   - 덩어리 → 흐름선 → 디테일 순서로
   - 한 올씩 그리려는 충동 참기

### 🖼️ 참고 이미지 키워드
`anime hair lineart tutorial` / `스타레일 머리카락 선화` / `Honkai Star Rail hair art style`

### 📝 오늘의 과제
덩어리 실루엣 + 흐름선 추가 연습 시트 제출 + 스타레일 캐릭터 머리카락 트레이싱 1개.

## 5일차 (평일/3시간) — 선화 종합: 반신 선화 완성

### 🎯 오늘의 목표
2주차에 배운 모든 선 기술을 통합하여 반신(상반신) 선화 1장 완성.

### 📖 선화 작업 순서 (프로 방식)

선화를 그리는 순서가 있다. 순서를 지키면 수정이 쉽고 완성도가 높아진다:

1. **러프 스케치** (밑그림 레이어, 불투명도 30~40%로 낮추기): 전체 구도 잡기. 빠르게, 틀려도 됨.
2. **주요 외곽선** (선화 레이어): 얼굴형, 머리카락 덩어리 실루엣, 몸통 외곽.
3. **세부 외곽선**: 눈/코/입 위치 잡기, 머리카락 세부 덩어리.
4. **내부 디테일**: 의상 선, 머리카락 흐름선, 얼굴 세부.
5. **최종 점검**: H키로 3번 이상 확인. 삐뚤어진 것 수정.

### ✏️ 실습 순서

1. 스타레일/명조 캐릭터 상반신 참고 이미지 선택 (서브 뷰에 고정)
2. 밑그림 레이어에 전체 러프 (10분 이내, 빠르게)
3. 밑그림 불투명도 30%로 낮추기
4. 선화 레이어 위에:
   - 외곽선부터 (굵게)
   - 머리카락 덩어리
   - 얼굴 세부
   - 의상
5. 작업 중 H키로 5회 이상 확인 및 수정
6. 밑그림 레이어 숨기기
7. 완성 상태에서 H키로 최종 확인

### 📝 오늘의 과제
반신 선화 완성본 제출 (밑그림 레이어 숨긴 상태). H키 확인 전/후 차이가 있었다면 어떤 부분을 수정했는지 짧게 설명.

## 6일차 (주말/4시간) — 주말 심화: 전신 선화 도전

### 🎯 오늘의 목표
상반신에서 전신으로 확장. 비율을 의식하며 전신 실루엣 + 선화.

### 📖 전신 선화 전에 알아야 할 것

전신은 비율이 핵심이다. 오늘은 비율을 정확하게 잡는 것이 목표이지, 디테일이 목표가 아니다.

간단한 비율 확인법:
- 머리 크기를 기준으로 몸 전체가 몇 배인지 (애니는 6~8등신)
- 어깨 넓이 = 머리 2개 크기 정도
- 허리 = 어깨보다 좁음
- 무릎 = 전체 키의 딱 절반

### ✏️ 실습 순서

1. 비율 가이드라인 그리기:
   - 세로선 하나 긋기
   - 머리 크기로 등분 표시 (8등분)
   - 각 기준점에 가로선

2. 가이드라인 위에 실루엣 잡기:
   - 머리, 몸통, 팔, 다리를 단순 도형으로
   - 디테일 없이 실루엣만

3. 실루엣 위에 선화 덧대기:
   - 외곽선 위주로
   - H키로 확인 필수
